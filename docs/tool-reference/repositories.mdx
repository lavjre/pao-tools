---
title: "Repositories"
description: "Clone helper repositories into the workspace for analysis or build support."
---

`fetch_repo` clones a Git repository into `/workspace`.

## Returned shape

`fetch_repo` returns the shared structured [Response API](/concepts/response-shapes).

## Parameters

- `repo_url`: HTTPS or SSH repository URL
- `version`: optional branch, tag, or commit
- `target_dir`: optional explicit destination inside `/workspace`
- `shallow`: whether to use a shallow clone
- `overwrite`: replace an existing destination when `true` (defaults to `false`)

For safety, an existing destination is never removed unless `overwrite` is explicitly
enabled.

```json
{"tool":"fetch_repo","arguments":{"repo_url":"https://github.com/lavjre/pao-tools.git","version":"main","target_dir":"/workspace/pao-tools","shallow":true,"overwrite":false}}
```

<Tip>
  If you omit `target_dir`, the server derives a directory name from the repository URL and clones into `/workspace/<repo-name>`.
</Tip>
