---
title: "Claude Desktop"
description: "Configure pao-tools for Claude Desktop over stdio."
---

Claude Desktop uses a local stdio MCP server definition.

## Config file location

- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Linux: `~/.config/Claude/claude_desktop_config.json`

<Warning>
  Use an absolute host path for the workspace mount. Claude Desktop will not expand project-local placeholders such as `${workspaceFolder}` in this config.
</Warning>

```json
{
  "mcpServers": {
    "pao-tools": {
      "command": "docker",
      "args": [
        "run",
        "--rm",
        "-i",
        "--cap-add=SYS_PTRACE",
        "--cap-add=SYS_ADMIN",
        "--security-opt",
        "seccomp=unconfined",
        "--security-opt",
        "apparmor=unconfined",
        "-v",
        "/ABSOLUTE/PATH/TO/YOUR/PROJECT/workspace:/workspace",
        "ghcr.io/lavjre/pao-tools:edge",
        "--stdio"
      ]
    }
  }
}
```

<Check>
  Restart Claude Desktop after editing the config, then confirm `pao-tools` appears in the MCP server list.
</Check>
