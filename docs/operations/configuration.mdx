This page covers the main knobs exposed by `pwno-mcp` itself.

## CLI flags

| Flag | Default | Purpose |
| --- | --- | --- |
| `--host` | `0.0.0.0` | bind host for the main HTTP server |
| `--port` | `5500` | bind port for the main HTTP server |
| `--attach-host` | `127.0.0.1` | bind host for the attach sidecar API |
| `--attach-port` | `5501` | bind port for the attach sidecar API |
| `--http-path` | `/mcp` | main HTTP transport path |
| `--stdio` | off | run as a stdio MCP server instead of HTTP |

## Environment variables

| Variable | Purpose |
| --- | --- |
| `PWNO_RUNTIME_ROOT` | override the root directory for session runtime data, process logs, and shared helper artifacts |
| `PAO_INLINE_RESPONSE_BYTES` | inline payload threshold in bytes; defaults to `1048576` (1 MiB). Larger payloads use artifact delivery |
| `PAO_ARTIFACT_CHUNK_BYTES` | default `read_artifact` range size; defaults to `262144` (256 KiB) |
| `PAO_ARTIFACT_TTL_SECONDS` | retention time; defaults to `259200` (72 hours). Set `0` to disable expiry |
| `PAO_ARTIFACT_QUOTA_BYTES` | soft store quota; defaults to `10737418240` (10 GiB). Set `0` to disable quota cleanup |
| `PAO_ARTIFACT_CLEANUP_TARGET_RATIO` | low-watermark after quota cleanup; defaults to `0.8` |
| `PAO_ARTIFACT_CLEANUP_INTERVAL_SECONDS` | background cleanup interval; defaults to `900`. Set `0` to disable periodic cleanup |
| `PAO_ARTIFACT_MIN_FREE_BYTES` | free disk reserve enforced before writes; defaults to `2147483648` (2 GiB) |
| `PAO_PWNDBG_EXPECTED_VERSION` | expected runtime pwndbg version; Docker sets this to its pinned release |
| `PAO_PWNDBG_INSPECTION_TIMEOUT_SECONDS` | per-command timeout for typed ELF/runtime inspection; defaults to `60` and can be increased for very large binaries |
| `BINARY_URL` | enables lazy RetDec analysis against an externally reachable binary URL |

These values control delivery, not data retention: crossing the inline threshold does
not truncate output. `read_artifact` also accepts an explicit `length` and does not
enforce a maximum range size.

Cleanup runs at startup, periodically, and before artifact writes. It deletes expired
unpinned artifacts first, then the oldest unpinned artifacts until quota and disk
targets are met. A single newest artifact may temporarily exceed the soft quota, but
the free-space reserve is a hard safety check. Pinned artifacts are never removed by
automatic cleanup.

## Example launches

<CodeGroup>

```bash Default HTTP
python -m pwnomcp
```

```bash Custom ports
python -m pwnomcp --host 0.0.0.0 --port 6600 --attach-port 6601 --http-path /mcp
```

```bash stdio
python -m pwnomcp --stdio
```

</CodeGroup>

## Operational defaults

- main HTTP endpoint: `http://127.0.0.1:5500/mcp`
- health check: `http://127.0.0.1:5500/healthz`
- attach sidecar: `http://127.0.0.1:5501/attach`
- workspace root inside the runtime: `/workspace`

Use [Docker and Compose](/operations/docker-and-compose) for launch recipes and [Troubleshooting](/troubleshooting) for common misconfigurations.
